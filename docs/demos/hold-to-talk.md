# Hold-to-talk voice demo

The [self-contained demo guide](../../skills/hold-to-talk/demo.md) includes
setup instructions, an architecture diagram, a recorded audio-file → local
Whisper → offline gptme transcript, and a desktop acceptance sequence.

The [experimental skill](../../skills/hold-to-talk/SKILL.md) supports existing
audio files, fixed-duration recording, and a held key. The documented run
verifies the file-input path; live microphone, keyboard and playback need
validation on the target desktop.
