# bobutils

Shared workspace utilities for gptme agents (stdlib-only).

## Overview

This package provides utilities and helpers used across gptme agent workspaces. It's designed to require only Python's standard library, making it lightweight and easy to integrate.

## Installation

```bash
uv pip install -e packages/bobutils
```
